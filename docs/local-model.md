## 可选的本机模型（实验性）

在设置的「模型」里打开「本机模型」，再点「加载本机模型」。在线配置会隐藏，切回在线模式时原来的地址、模型名和 Key 仍在。本机模式不需要 API Key，也不需要安装 Ollama。刷新后若仍选择本机模式，会自动打开模型面板；模型未就绪时发送指令也会打开该面板，并保留输入。点击加载、等待就绪后再发送即可，底部模型标识只在就绪时显示。

使用 WebLLM 在浏览器的 WebGPU 上运行量化的 `Qwen3-0.6B-q4f16_1-MLC`。首次需要联网下载数百 MB 的模型，并缓存网页和运行库；显存需求约 1.4 GB，另需留出三维场景的开销。先以支持 WebGPU 的桌面浏览器为目标。本机推理需要后台 Worker 可用。下载由用户点击触发，模型运行库只在 Worker 中按需加载，不会在普通在线模式下加载。

本机模型先提供四种基础动作：观察、移动、转向、升降身体。可以试「向前走一米」「右转九十度」「把身体抬高到一米」。每条指令独立执行，不带入之前的对话，每次最多进行 6 轮模型调用。复杂任务、物品操作和模型主动写记忆请使用在线模式。小模型可能遗漏参数或理解错误；动作仍经过现有工具校验，失败结果会交回模型，每次动作也能用「停止」中断。

对话仍记录到本机日记；日记摘要复用同一个本机模型，不会回退到在线 API。摘要与动作共用一个串行推理队列，取消某条指令不会取消其他排队请求。本机上下文上限为 4096 token，由引擎按实际分词检查；超限时会提示缩短指令。达到生成长度限制的回复不会交给动作工具执行。自动整理失败时沿用现有的裁剪策略。

正式构建显示「网页已缓存」且模型加载成功后，可以断网重开页面，再点「加载本机模型」从缓存加载。网页由 Service Worker 缓存，权重、分词器和 WASM 由 WebLLM 缓存。网页缓存与模型加载独立进行；网页缓存失败不会阻止本机推理，但此时不能保证断网重开页面。浏览器清理站点数据或回收缓存后需要重新联网下载。「释放缓存」卸载当前模型、释放运行时占用，保留下载缓存。下载、读取缓存和准备图形计算分别显示阶段进度；下载阶段的剩余时间按当前速度估算。云端进度同步仍需要网络。

模型文件和 WASM 地址固定到与 WebLLM 0.2.87 配套的提交版本，避免远端更新后与已有缓存不匹配。从旧的浮动地址升级到固定地址时，可能需要重新下载一次；之后刷新页面仍可复用缓存。

网页离线缓存仅在 `pnpm build` 后的正式构建生效；`pnpm dev` 用于开发，不安装 Service Worker。部署支持根路径或子路径。核心页面、脚本、样式、字体和构建资源必须全部缓存成功，可选的公开图片缓存失败不阻止安装。新版本的离线缓存安装后，在旧页面全部关闭后接替旧版本；只清理同一部署路径的旧网页缓存，不缓存 API 响应和密钥，也不会清理其他部署或 WebLLM 的模型缓存。
