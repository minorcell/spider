# 模型接入说明

[返回 README](../README.md#接入模型)

## 使用 Ollama

先按 [Ollama 官方说明](https://docs.ollama.com/)安装，在终端启动服务。

```bash
ollama serve
```

另开一个终端，用 `ollama pull <模型名>` 下载模型，将 `<模型名>` 替换为要使用的实际名称。建议选择能遵循指令并调用工具的模型。

在 蛛小八的模型设置中点击 Ollama，页面会使用 `http://localhost:11434/v1`，并尝试读取本机模型列表。点击已下载的模型即可填入 Model ID，无需 API Key。

如果浏览器提示跨域请求被拒绝，需要在启动 Ollama 时允许页面所在的来源。例如，使用项目默认的本地开发地址时，可以这样启动。

```bash
OLLAMA_ORIGINS=http://localhost:3300 ollama serve
```

从在线站点访问本机服务时，将来源替换为 `https://spider.minorcell.top`。如有旧的 Ollama 服务正在运行，应先停止，再带环境变量启动。浏览器还可能要求授权网站访问本地网络。

## 使用在线模型服务

在服务商处获取 API Key，确认可用的模型标识和 OpenAI 兼容接口地址，再填写 Base URL、Model ID 和 API Key。

DeepSeek 快速入口会填入 `https://api.deepseek.com/v1` 和项目预设的 `deepseek-flash`。如果账户可用的模型不同，请修改 Model ID，以服务商实际提供的标识为准。

浏览器直接调用模型服务，因此接口需要允许页面所在来源的跨域请求。只有服务端可访问、未开放浏览器跨域访问的接口，不能直接使用。

## 常见问题

| 现象                           | 检查方法                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 提交指令后没有开始行动         | 检查模型设置是否完整。Base URL 和 Model ID 为必填项，除 Ollama 外还需要 API Key                        |
| 请求返回认证或模型错误         | 检查密钥是否有效、Model ID 是否属于当前服务，以及账户是否有调用权限                                    |
| 无法连接，或浏览器提示跨域错误 | 检查服务是否启动、地址是否可达，以及服务是否允许当前页面来源；使用 Ollama 时也检查浏览器的本地网络权限 |
| 关闭「思考」后报错             | 该设置会请求跳过推理，接口可能不支持对应参数，可以重新开启后尝试                                       |
| 能回复文字，但任务执行不完整   | 检查模型是否适合工具调用；模型的行动选择也可能因环境和上下文而失败                                     |

「思考」开启时使用模型默认的推理设置，关闭时请求跳过推理。项目还对以文本形式输出工具调用的模型做了兼容处理，但不同模型的行动表现仍会有差异。
