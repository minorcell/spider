# 存档与同步

[返回 README](../README.md#进度与数据)

## 本地保存

世界进度默认保存在当前浏览器中。存档包括蜘蛛的位置、携带物品、已标记的地点和待完成的指令。日记单独记录对话摘要和蜘蛛留下的内容，模型设置也在本地保存。

本地存档依赖浏览器的站点存储。清除站点数据会移除存档；不同浏览器、浏览器配置或站点地址拥有各自独立的数据。

世界和模型设置共用[持久化缓存层](../src/client/store/cache.ts)。内存保存当前状态，IndexedDB 保存检查点，localStorage 保存同步恢复记录。新世界启动后就会保存；模拟有变化时最多每十秒做一次检查点，工具调用和结果合并写入，提交指令、切到后台或关闭页面时补存。

关闭页面时无法保证异步 IndexedDB 写入完成，因此程序持续保存检查点，并在离开时同步暂存完整状态。串行写入和恢复记录的版本比较用于防止旧写入覆盖较新的状态。

[世界存储层](../src/client/worldStore.ts)负责存档校验和多标签页写入协调。后打开的标签页不会覆盖仍持有有效租约的页面，租约过期后才能接手。空闲时只续写一个独立的小租约键，避免反复写入完整快照。

## 可选的云端同步

在设置的「云端」中填写 S3 兼容对象存储的端点、区域、桶和访问密钥。浏览器直接访问对象存储，桶需要配置允许页面来源的跨域访问规则。

连接检查通过后，世界和日记会保存为 `spider/world.json`。云端存档不包含模型设置、模型密钥、用量记录或对象存储密钥。对象存储密钥保存在当前浏览器，用于对存储请求签名。

换到另一台设备后，需要在新设备中重新配置云端和模型。本地没有存档时，可以从云端恢复；本地和云端都有改动时，页面会让你选择一份继续，另一份保留在云端。

另一台设备仍持有写入租约时，当前设备不会上传，直到在页面中点击「改在这台电脑玩」接手。跨设备协调由[云端同步引擎](../src/client/cloud/engine.ts)处理。

关闭页面时，程序会尝试发送最后一次上传，大小上限为 60,000 字节。较大的存档会留待下一次打开时继续同步，因此关闭页面并不代表云端已经收到最后的全部进度。
